# Structure-Aware Spatial Kernels for GP-PHS

Code for **Structure-Aware Spatial Kernels for Gaussian Process Distributed
Port-Hamiltonian Systems** by Tianyi Yang and Thomas Beckers. The manuscript has
been submitted to the **2027 American Control Conference (ACC)**.

The experiments compare Gaussian process kernels for learning Hamiltonian
gradients in a one-dimensional soft rod with spatially varying stiffness.
Evaluation includes effort prediction, dynamical rollouts, energy error, and
integrability. All data are generated by the simulator; no external dataset
download is required.

## Setup

From the repository root, create a Python 3.13 environment and install the
dependencies:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

On Windows, activate the environment with `.venv\Scripts\activate`.
The rollout code runs on CPU. MP4 output also requires FFmpeg on your system path.

The recorded development environment uses Python 3.13.5. To match its direct
dependency versions, replace the unpinned requirements installation above with:

```bash
python -m pip install \
  numpy==2.4.6 scipy==1.17.1 matplotlib==3.10.9 \
  torch==2.13.0 gpytorch==1.15.2 tqdm==4.70.0
```

## Reproduce the experiments

### Main experiments

```bash
python run_experiments.py
```

The default matrix evaluates a constant-stiffness baseline and compares the
Baseline, SD-RBF, and SD-matched kernels on periodic, C2, and piecewise stiffness
profiles. It uses five seeds and up to five worker processes, saving results to
`data/paper_experiment.pkl`.

Edit `build_paper_experiments()` to change profiles, kernels, sampling, or training
settings. Adjust `ParallelConfig` in `compute_main_experiment()` to control
parallel execution. Configuration fields are defined in `config.py`.

### Figures and reports

After completing the main experiments, run:

```bash
python report.py
```

This prints the aggregate metric table and generates
`plots/rollout_experiments.pdf` and `plots/C2_baseline.mp4` from the saved results.
Reporting does not retrain the models.

Edit the final block of `report.py` to select the input artifact and animation.
The paper figure's profile and time-step selection is in `plot_main_experiment()`.
If you only need the table and PDF, omit the
`create_rollout_video_from_artifact()` call; FFmpeg is then unnecessary.

### Changepoint robustness

In `compute_main_experiment()` in `run_experiments.py`, replace
`build_paper_experiments()` in the `run_experiment_matrix()` call with
`changepoint_robostness_experiments()`:

```python
experiment_specs=changepoint_robostness_experiments(),
```

This selects the piecewise-stiffness study with perturbed changepoint locations
and widths. To preserve the main experiment results, also change the final
`compute_main_experiment()` call to use a separate output file:

```python
compute_main_experiment(save_results_path="./data/changepoint_robustness.pkl")
```

Run `python run_experiments.py` again. The runner prints the aggregate metric
table. The default `report.py` configuration expects the main experiment
artifact; adapt its profile and model selections before reporting on the
robustness results.

Run all commands from the repository root. Output directories are created
automatically. Generated results and figures are excluded from Git.

## Repository structure

| File or directory | Purpose |
| --- | --- |
| `run_experiments.py` | Experiment definitions, training, evaluation, and result saving |
| `report.py` | Tables, paper figures, and example animation |
| `config.py` | Simulation, model, training, and evaluation settings |
| `simulator.py` | Reference soft-rod dynamics and stiffness profiles |
| `kernels.py`, `model.py` | GP kernels and model training |
| `data_processing.py` | Training-point sampling and normalization |
| `rollout.py` | GP-PHS integration and displacement reconstruction |
| `metrics.py`, `plotting.py` | Evaluation metrics and visualization |
| `data/`, `plots/` | Generated experiment results and figures |
